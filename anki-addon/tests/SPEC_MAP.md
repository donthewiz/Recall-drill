# Vitest spec → Python test map

Every vitest spec file (30 files, 271 tests) and where its behavior is checked in the add-on. Phase 1a started this map, and Phase 1b finishes it.

**Statuses:**
- **ported**: every `it(...)` has a pytest twin, one Python test per TS `it`, with the TS test name in the docstring.
- **partly ported**: the `it`s that only touch `grading`/`items` are ported. The rest are Phase 1b or N/A, as noted.
- **golden**: covered by replaying recorded TS outputs from `tests/golden/` (generated by `tools/export_golden.ts`).
- **Phase 1b**: session-engine behavior (`session.ts`, `estimate.ts`, `progress.ts`, `history.ts`), ported in Phase 1b.
- **N/A**: web-app UI or `localStorage` behavior the add-on doesn't have, with a reason.

Golden files (Phase 1a):
- `prng.json`: `hashSeed`, `mulberry32`.
- `jscompat.json`: the JS built-ins the engine relies on.
- `grading.json`: `norm`, `exactMatch`, `computeWordDiff`, `grade`.
- `items.json`: everything in `items.ts`.
